CADCopilot - GPU host (the PC with the RTX 4070)
================================================

You're lending your GPU so Advay's Inventor copilot runs fast.

ONE-TIME:
  1. Install Ollama:  https://ollama.com/download   (open it once so it's set up)
  2. If you and Advay are NOT on the same Wi-Fi, both of you install
     Tailscale (https://tailscale.com) and sign in to the same account.

EVERY TIME YOU WANT TO HELP HIM BUILD:
  1. Double-click  start.bat
  2. Click "Yes" on the admin prompt (it only needs that for the firewall).
  3. Wait for it to say READY, then send Advay the address it prints
     (looks like  http://192.168.x.x:11434  or  http://100.x.x.x:11434 ).
  4. Leave the minimized "Ollama Server" window OPEN while he works.
     Closing it stops the server.

That's it. First run downloads the model (~9 GB) once; after that it's instant.
